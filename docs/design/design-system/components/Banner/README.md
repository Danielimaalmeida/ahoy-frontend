# Banner

An inline callout for something the person must know before acting.

| Variant                       | Use                                                                                                                                       |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `ah-banner--notice`           | "This voyage changed since you opened it" (409 conflict), the planned-screen note. Always says what changed and that typed text was kept. |
| `ah-banner--error`            | The anchored explanation, "someone decided first", reject warnings. Plain words first; the technical line (`ah-tech`) last.               |
| `ah-banner--info` / `ah-cost` | Cost confirmation: "This may spend up to 10.2 AIU", who is billed, and that anyone can stop it.                                           |

Copy is calm and specific: what happened, what it means, what to do. Never blame, never "Oops". A tooling failure never reads like a gate verdict.
