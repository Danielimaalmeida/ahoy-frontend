# ChoiceCard

A radio option drawn as a card, used where each choice has a consequence to read: the human-gate decision (Approve, Send back, Reject).

Each card states what happens next in `ah-choice__desc`: "The voyage moves on to implementation", "This would be round 3 of 4", "The voyage runs aground (blocked)". The checked card gets an accent ring and `info-bg`. Show the reason field under the cards when the choice needs one, and name the actor it will be recorded as.
