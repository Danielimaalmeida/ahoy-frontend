# ShipsLog

The activity timeline: every event on a voyage, newest first, with who did it. Updates arrive live.

Dot colours group events: `ah-log__dot--human` (a person acted), `--pass` (a gate passed), `--wait` (waiting on a person), plain (the system). The event name is bold, details follow in plain text, and run ids link to run detail. Show the actor's e-mail, or "Ahoy" for the system.
