# EmptyState

What a list or panel shows when it has nothing: an icon, a short title, one sentence on what will appear, and one way forward.

Keep the nautical voice light and the meaning exact: "Calm seas. Nothing needs you right now." For a filter with no results, say which filter and offer to clear it. Errors are not empty states; use the error pattern (title, plain explanation, Try again, then the request id in `hash`).
