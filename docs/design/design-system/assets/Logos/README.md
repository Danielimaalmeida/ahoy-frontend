# Logos

The Ahoy mark is a ship's wheel drawn with the 1.8px icon stroke.

- `ahoy-mark.svg`: ink is `accent` (#1A64D6). Use on light surfaces, at 20–28px in the top bar beside the word "Ahoy" (Plus Jakarta Sans 700, 17px).
- `ahoy-mark-white.svg`: ink is white. Use on `accent` or dark fills only.
- `ahoy-app-icon.svg`: the white wheel on an accent square, corner radius 22/96. Favicon and app tiles.

Keep clear space of half the mark's width around it. Don't recolour it to a status colour, outline it or set it on a photo.
